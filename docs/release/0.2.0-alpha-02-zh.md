# SSB Runner 0.2.0-alpha-02 更新说明

版本：`0.2.0+200002`

本版本是 `0.2.0-alpha-01` 的缺陷修复版本，集中修复 alpha-01 中暴露的通联流程、交换内容、界面与日志导出问题。**本版本不引入新的破坏性变更**。

> 如果你是从 `0.1.0-alpha` 或更早版本升级，请先阅读 [0.2.0 更新说明](https://github.com/SSBContestRunner/ssb_runner/releases/tag/v0.2.0-alpha-01) 的「重要变更」一节：应用标识变更会导致偏好设置重置，日志位置改变，数据库会自动升级。

## 通联流程修复

- **Search & Pounce（S&P）改为独立的两段式状态机。** 之前 S&P 复用 Run 模式状态机并额外加了一段确认状态，与实际通联节奏不符，需要多按一次 Enter。现在 S&P 拥有独立状态，**第二次 Enter 即完成 QSO**，流程与 N1MM 一致：听到对方 CQ → Enter 发我方呼号 → 抄收对方序号 → Enter 发我方交换并记录 QSO → 对方 TU 结束 → 进入下一个 CQ。Run 模式保持不变。
- **呼号判读改为前缀匹配。** 是否让对方重复呼号，现在以「前缀匹配」为准：当抄收到的呼号是正确呼号的前缀（即使差异超过阈值），或差异在阈值之内时，对方才会重复；完全抄对或完全空白都不再触发重复。该逻辑统一应用于提交呼号、呼号合法性校验与回放选台。
- **补齐「对方重复呼号」状态下的提交。** 之前输入部分呼号后按 `<his>` 会进入「对方重复呼号」状态，补全呼号再按 Enter 时发出的提交事件在该状态下未处理，交换因此不播放；现在会正确转入发送我方交换并播放「呼号 + 交换」。
- **该状态下 F5 现在也能重放呼号。** 完整抄对则进入询问交换；仍匹配前缀则继续重放；偏差过大则退回等待提交。
- **更正呼号后先回读。** 在抄收交换阶段更正了错误呼号时，现在会先用我方声音把更正后的呼号回读一遍（紧接在 `TU_QRZ` 之前），确保双方对呼号达成一致后再记录 QSO。
- **Esc 只停止发送。** Esc 现在仅停止当前发送，不再改动状态机（移除了 Run 模式下把状态倒回静默变体的行为，并删除了已不可达的 Cancel 事件与处理）；与 N1MM 一致，不再干扰 QSO 与操作员的输入。
- **S&P 的 CQ 重放不再被截断。** 修复搜索模式下按 F7（AGN）时对方 CQ 听不到的问题：重试时把对方的 CQ 排在 AGN 之后播放，而不是重置音频流把它丢掉。

## 交换内容修复（比分正确性）

- **对方交换改由对方呼号推导**，而不再是任意的 `1..max` 数字——之前生成的交换经常与对方身份不符（IARU/JIDX 分区、ARRL 功率与 W/VE 州/省），ARRL 还会看起来像序号。现在各比赛按对方身份推导：
  - **CQ WW**：对方的 CQ 分区。
  - **IARU HF**：对方的 ITU 分区（美国台按呼号区细化）。
  - **JIDX**：日本呼号发其呼号区内的县号，否则发 CQ 分区。
  - **ARRL DX**：W/VE 台发呼号区对应的州/省，DX 台发功率。
- **美国分区按呼号区细化。** CQ WW / JIDX 的美国台 CQ 分区、IARU 的 ITU 分区不再取实体默认值（例如 W6/W7 → CQ 3 区，W0/W5 → CQ 4 区）。
- **ARRL DX 我方交换按角色区分。** W/VE 操作者填写两位的州/省（按 ARRL 列表校验），DX 操作者填写功率；**对应角色的字段未填写前，RUN 拒绝开始**。
- **JIDX 我方县号限制在本呼号区范围内**填写。
- **ARRL 允许字母交换。** 接收交换的输入不再仅限数字。
- **cty 资源更新并重建前缀缓存（schema 版本提升）。** 修正了此前影响计分、JA / W-VE 识别与口音选择的部分过期实体编号。升级后**首次启动会自动重载前缀表**，可能比平时略慢，之后恢复。

## 界面修复

- **F1–F8 标签在最小窗口宽度下被裁剪。** 原来固定四列网格、按键高度由宽高比推算，在 1024px 最小宽度下每个键缩到约 56×23px，标签（如「F1 CQ」）被裁切。现在改为两行、共享可用高度，标签可换行到第二行，并减小内边距，始终完整可读。
- **屏幕上的 F1–F8 按钮点击无效。** 操作区 cubit 从未订阅比赛运行流，鼠标点击被转发到空处理器后静默丢弃（键盘快捷键却正常）。现在点击与快捷键一致生效。
- **Duration 输入框的两个问题：** 退格后焦点会跳到呼号框，且值不能即时钳制。控制器与焦点节点移入 options cubit，组件保持无状态且跨重建稳定；**聚焦期间清空保持空白、失焦回填**，超上限时（如输入 999）立即显示钳制值（120）。
- **Windows 上中文/日文输入法组合输入被打断。** `UpperCaseTextFormatter` 会在组合输入尚未提交时就重建文本值，导致 IME 认为组合结束并提交原始拼音字母，把杂散字母灌进 Call / Exchange / 呼号字段。现在**组合期间不转换，提交后才大写**。
- **侧栏 Contest 区块字段被裁剪。** 370px 宽度下 Name 下拉与 Exchange 字段并排显示时，ARRL 这类较长的交换标签（如「59 State/Province (W/VE) / 59 Power (DX)」）无法容纳，两者都被裁切。现在改为上下堆叠、全宽显示，交换标签可换行。
- **比赛名称去掉冗余的 SSB 后缀**（如「CQ WPX SSB」→「CQ WPX」）。

## 日志导出修复

- **导出日志改用系统保存对话框选择位置。** 原来通过 `getApplicationDocumentsDirectory()` 写入，在 macOS 沙盒发布版中会落在用户找不到的应用容器内。现在由系统另存对话框让你选择保存位置；**取消对话框视为无操作**，不再把过期路径复制到剪贴板。

## 其它

- **CI**：assets 子模块改用 SSH URL（本地推送使用开发者自己的 SSH key）；CI 运行器没有密钥，因此在 checkout 前把 `git@github.com:` 改写回 `https://github.com/` 以克隆公共仓库。
- 版本号提升到 `0.2.0+200002`。

## 平台与安装

正式发布仅包含桌面平台：Windows x64、macOS 通用（Apple Silicon 与 Intel）、Linux x86_64（glibc 2.35+）。

当前安装包**未签名**：

- **Windows** 可能提示未知发布者，选择「更多信息 → 仍要运行」。
- **macOS** 请右键应用选择「打开」，或在「系统设置 → 隐私与安全性」中放行。
