# SSB Runner 0.3.0-alpha04 更新说明

版本：`0.3.0+300004`

**本版本仍是 0.3.0 的 alpha 预览版，不是稳定版。** 本版只调整 Windows 安装器，**应用代码、数据库结构与事件日志格式都没有变化**，升级后训练记录与设置原样保留；如果要记录真实比赛，请继续使用 `0.2.1`。

从 `0.3.0-alpha03` 升级可以直接覆盖安装。

## Windows 安装器：支持四种安装语言

- **安装向导支持英文、简体中文、繁体中文、日文**，按系统语言自动匹配；系统语言不在其中时才弹出语言选择框。
- **修复「声明了中文却只出英文」**。此前配置里写了 `locales: [en, zh]`，但打包工具的内置模板只去 Inno Setup 的 `Languages\` 目录找语言文件；简体/繁体中文在 Inno Setup 里始终是非官方翻译，只存在于 issrc 源码仓库的 `Files\Languages\Unofficial\`，安装包本身不会携带，找不到时被**静默跳过**，产物最终只有英文。
- **语言清单改由安装脚本唯一维护**。Windows 打包改用自定义 Inno Setup 模板，`[Languages]` 固定为上述四项；语言文件路径写错会在编译期直接报错，不会再静默退化。代价是新增应用语言时需同步该模板。
- **构建期接入语言文件**。简体/繁体中文 `.isl` 已内置在仓库，CI 在打包前把它们复制到 Inno Setup 安装目录，并断言四个语言文件齐全，缺失时带明确信息失败。

## Windows 安装器：去掉「开机启动」

- **安装向导不再出现「开机启动」勾选项**，全新安装也不会在启动目录写入 `SSB Runner.lnk`。
- 此前 `launch_at_startup: false` 只能让该勾选框默认不勾选，无法移除：内置模板无条件生成对应任务和启动目录快捷方式，必须替换模板才能根除。
- 「选择附加任务」页现在只剩「创建桌面图标」，且仍默认不勾选。
- **已通过旧版安装并勾选过开机启动的用户不会被自动清理**，该快捷方式需手动删除，或卸载后重新安装。

## Windows 安装器：向导显示应用图标

- 安装向导右上角改为显示应用 logo（提供 58/116/174 三档尺寸，按当前 DPI 缩放取最接近的一档），不再使用 Inno Setup 的默认占位图。

## 发布流程

- **发布说明中的 SHA-256 指纹一节改为英文**，与公开的发布页面保持一致；校验方式与指纹来源不变。

## 已知限制（Alpha）

- **仅供预览。** 请把 0.3.0-alpha04 当作测试版本；真实比赛记录请使用 `0.2.1`。
- **不可降级。** 数据库已迁移到 v7。`0.2.x` 版本可能无法打开本 alpha 写出的数据库，切回旧版前请先导出/备份 QSO 历史。
- **旧录像无法证明归属。** 会话重放依赖 0.3.0 新增的开局记录头。由 `0.2.1` 或更早版本录制的待重放会话会被拒绝，并改为按当前设置开局。
- **没有在线排行榜。** 设计文档中的分数上传与服务端重放校验不在本 alpha 范围内。
- **安装包未签名**（见下文）。
- Linux 安装包要求 glibc 2.35 或更高版本。

## 平台与安装

仅打包桌面平台：Windows x64、macOS universal（Apple Silicon 与 Intel）、Linux x86_64（glibc 2.35+）。

安装包**未签名**：

- **Windows** 可能提示未知发布者 — 选择 *更多信息 → 仍要运行*。
- **macOS** — 右键点击应用并选择 *打开*，或在 *系统设置 → 隐私与安全性* 中允许。
