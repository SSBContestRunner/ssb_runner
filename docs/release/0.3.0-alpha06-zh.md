# SSB Runner 0.3.0-alpha06 更新说明

版本：`0.3.0+300006`

**本版本仍是 0.3.0 的 alpha 预览版，不是稳定版。** 本版修复了导致 `0.3.0-alpha05` Windows 冒烟测试失败的退出卡死问题：在音频引擎仍在初始化时关闭窗口，会出现「窗口消失但进程永远留在任务管理器」。**数据库结构与事件日志格式都没有变化**，升级后训练记录与设置原样保留；如果要记录真实比赛，请继续使用 `0.2.1`。

从 `0.3.0-alpha05` 升级可以直接覆盖安装。

## Windows：启动期间关窗不再残留后台进程

- **现象**。窗口出现后的最初几百毫秒内（此时 SoLoud 正在打开音频设备）关闭窗口，窗口会消失，但进程永久留在任务管理器中。既没有崩溃，日志也不再增加：进程卡死在 `ExitProcess` 内部。
- **原因**。`SoLoud.isInitialized` 在整个初始化期间都是 `false`，旧的退出流程因此跳过了 deinit 并直接答复退出请求。引擎析构本身正常（取证时间线里只用了 58 ms），`wWinMain` 也正常返回，但 `ExitProcess` 随后会逐个调用已加载 DLL 的 `DllMain(DLL_PROCESS_DETACH)`，SoLoud 插件在这里等待一个只有其初始化线程才能 signal 的内核对象，而该线程此时已不存在。Dart 保底定时器这一刻帮不上忙：Dart VM 已经随引擎销毁关闭。
- **修复**。退出流程现在跟踪初始化状态：最多等待 2 s 让在飞的初始化收敛，然后**无条件**有界地释放引擎（无论正在运行、从未启动还是启动失败），只有当引擎处于「从未初始化」或「已完成释放」两种确定状态时才答复退出请求；其余情况直接终止进程，跳过 CRT 与 DLL 卸载阶段而不是在其中挂死。
- **关窗后启动流程停止派发新步骤**，启动中关窗不再与剩余启动步骤竞争。
- 该问题只在关窗恰好落在约 30–400 ms 的初始化窗口内时复现，因此表现为偶发，且此前只在 CI 暴露。

## Windows：原生看门狗

- **新增原生看门狗，覆盖 Dart 已经无法介入的阶段。** 它在收到 `WM_CLOSE` 时武装，等待 5 s；若 `ExitProcess` 仍未结束就终止进程。原有 Dart 保底继续覆盖「清理卡死」，两者合起来把整条退出路径限制在 5 s 内。
- 看门狗的事件与线程在关窗时才惰性创建，正常运行的启动开销与线程数不变。

## 退出诊断

- 退出流程现在会在原生启动时间线旁写一份同步的 `exit_<pid>.log`，包含 `enter`、`settled`、`deinit_done`、`answering_exit`、`hard_exit_*`、`fallback_fired` 等标记。常规应用日志是带缓冲的，窗口消失后无法证明发生了什么。

## Windows 冒烟测试：扫描关窗时机

- 冒烟测试改为在多个不同延迟下关窗，避免「音频初始化中关窗」这一时间窗再次被无声放过。
- 发生挂死时会先抓取 minidump 与线程栈，再强杀进程，而不只是断言进程还活着。

## 工程配置：analyzer 门禁纳入 info 级告警

- CI 改为 `flutter analyze --fatal-infos`，info 级 lint 也纳入门禁，避免同类存量再次堆积。
- Dart 3.13 私有命名形参带来的 51 条 `prefer_initializing_formals` 已修复，所有调用点的实参名保持不变；同时删除了无引用的 `CQ_WPX` 常量。
- 全仓库按 Dart 3.13 格式化器统一格式化一次，后续 `dart format` 不再产生无关 diff。以上均无行为变化。

## 工程配置：测试输出降噪

- 69 条 `WARNING (drift)` 已清零。原先为每个 fake 或 harness 新建 `AppDatabase` 的 4 个测试文件改为每个文件共享一个「永不打开」的实例，与其余 UI 测试既有约定一致；唯一一个故意同时保留两个实例的测试改为局部抑制该告警。
- 29 条应用日志 WARN 保持原样：它们来自故意断言失败/拒绝路径的测试，去掉会削弱测试有效性。

## 已知限制（Alpha）

- **仅供预览。** 请把 0.3.0-alpha06 当作测试版本；真实比赛记录请使用 `0.2.1`。
- **不可降级。** 数据库已迁移到 v7。`0.2.x` 版本可能无法打开本 alpha 写出的数据库，切回旧版前请先导出/备份 QSO 历史。
- **旧录像无法证明归属。** 会话重放依赖 0.3.0 新增的开局记录头。由 `0.2.1` 或更早版本录制的待重放会话会被拒绝，并改为按当前设置开局。
- **没有在线排行榜。** 设计文档中的分数上传与服务端重放校验不在本 alpha 范围内。
- **安装包未签名**（见下文）。
- Linux 安装包要求 glibc 2.35 或更高版本。
