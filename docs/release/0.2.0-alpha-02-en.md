# SSB Runner 0.2.0-alpha-02 Release Notes

Version: `0.2.0+200002`

This release fixes the bugs found in `0.2.0-alpha-01`, covering the on-air flow,
exchange content, UI, and log export. **It introduces no new breaking changes.**

> If you are upgrading from `0.1.0-alpha` or earlier, read "Important Changes" in
> the [0.2.0 release notes](https://github.com/SSBContestRunner/ssb_runner/releases/tag/v0.2.0-alpha-01) first: the application identifier change
> resets preferences, moves the log location, and upgrades the database
> automatically.

## On-air Flow Fixes

- **Search & Pounce (S&P) now has its own two-Enter state machine.** S&P ran on
  the Run mode machine with an extra confirmation state, which did not match the
  real exchange and needed a third Enter. It now has dedicated states and
  **commits on the second Enter**, matching N1MM: hear the CQ → Enter sends our
  callsign → copy his serial → Enter sends our exchange and logs the QSO → his TU
  closes it → the next CQ follows. Run mode is unchanged.
- **Callsign repeat detection now uses a prefix match.** The other station
  repeats its callsign when the operator's copy is a **prefix** of the correct
  call (even if the diff exceeds the threshold) or when the mismatch stays within
  the threshold. Exact copies and empty input no longer trigger a repeat. This is
  applied consistently to the submit-call transition, the callsign validity
  check, and playback selection.
- **Submit now works from the "he repeats the correct call" state.** After
  pressing `<his>` with a partial callsign the machine enters that state;
  completing the call and pressing Enter emitted a submit event that state did
  not handle, so the exchange never played. It now transitions correctly and
  plays "call + exchange".
- **F5 replays the callsign from that state too.** A fully copied call advances
  to asking for the exchange; a still-matching prefix keeps replaying; a large
  mismatch returns to waiting for the submit.
- **A corrected callsign is read back before signing off.** When the operator
  fixes a mis-copied callsign while entering the exchange, the corrected call is
  now read back in the operator's own voice (immediately before `TU_QRZ`) so both
  sides agree before the QSO is logged.
- **Esc only stops sending.** Esc now just drops the audio and leaves the state
  machine alone (the Run-mode behaviour that rewound to a silent variant is gone,
  and the now-unreachable Cancel event and its handlers were removed), matching
  N1MM without disturbing the QSO or the operator's input.
- **S&P CQ replay is no longer cut off.** Pressing F7 (AGN) in search & pounce
  played only the runner's CQ because the retry reset the audio stream and
  discarded the AGN. On a retry the CQ is now queued behind our own clip, so the
  operator hears AGN then the runner again.

## Exchange Content Fixes (Scoring Correctness)

- **The received exchange is now derived from the caller's callsign**, not an
  arbitrary `1..max` number — the old values often did not match the caller
  (IARU/JIDX zones, ARRL power vs W/VE state), and ARRL looked like a serial.
  Each contest now derives it from the caller's identity:
  - **CQ WW**: the caller's CQ zone.
  - **IARU HF**: the caller's ITU zone (US calls refined by call area).
  - **JIDX**: JA callers send a prefecture in their call area, otherwise a CQ
    zone.
  - **ARRL DX**: W/VE callers send a state/province by call area, DX callers
    send power.
- **US zones are refined by call area.** CQ WW / JIDX no longer use the entity
  default CQ zone for US callers, and IARU no longer uses the entity default ITU
  zone (for example W6/W7 → CQ zone 3, W0/W5 → CQ zone 4).
- **ARRL DX's own exchange is role-driven.** A W/VE operator configures a
  two-letter state/province (validated against the ARRL list); a DX operator
  configures power. **RUN refuses to start until the field for that role is
  filled in.**
- **The JIDX operator prefecture is constrained to its own call area.**
- **ARRL accepts letter exchanges.** The received exchange input is no longer
  digits-only.
- **The cty asset was rebuilt and the prefix cache is reloaded (schema version
  bumped).** This fixes stale entity ids that scored, JA / W-VE detection, and
  accent selection used to read. **The first launch after upgrading reloads the
  prefix table** and may be slightly slower; it returns to normal afterwards.

## UI Fixes

- **F1–F8 labels were clipped at the minimum window width.** The pad used a fixed
  four-column grid whose cell height was derived from `childAspectRatio`, so at
  the 1024px minimum each key shrank to about 56×23px and the label (e.g.
  "F1 CQ") was clipped. It is now two rows that share the available height, the
  label wraps onto a second line, and the button padding is reduced, so the key
  text is always fully readable.
- **On-screen F1–F8 button clicks did nothing.** The operation-area cubit never
  attached to the contest running stream, so mouse clicks were forwarded to a
  null handler and silently dropped, while the keyboard shortcuts kept working.
  Clicks now work the same as the shortcuts.
- **Two Duration field issues:** focus jumped to the callsign box on backspace,
  and the value could not be clamped live. The controller and focus node now live
  in the options cubit so the widget stays stateless and stable across rebuilds;
  **an emptied box stays blank while focused and is refilled on blur**, and a
  value over the limit (e.g. typing 999) immediately shows the clamped value
  (120).
- **Chinese/Japanese IME composition was broken on Windows.**
  `UpperCaseTextFormatter` rebuilt the text value while composition was still
  uncommitted, so the IME treated the composition as finished and committed the
  raw phonetic letters, spilling stray letters into the Call, Exchange, and
  callsign fields. It now **leaves text under composition untouched and
  uppercases only once the composition is committed**.
- **Sidebar Contest fields were clipped.** At the 370px sidebar width, the Name
  dropdown and the Exchange field could not share one row — ARRL's long label
  ("59 State/Province (W/VE) / 59 Power (DX)") did not fit and both fields
  rendered clipped. They are now stacked vertically at full width, with the
  exchange label wrapping.
- **Contest names dropped the redundant SSB suffix** (e.g. "CQ WPX SSB" → "CQ
  WPX").

## Log Export Fix

- **Export logs now picks its location via a system save dialog.** It wrote to
  `getApplicationDocumentsDirectory()`, which resolves inside the app container
  on sandboxed macOS releases, so the file landed somewhere users could not find.
  The OS save dialog now lets you choose the target; **a cancelled dialog is a
  no-op** and no stale path is copied to the clipboard.

## Other

- **CI**: the assets submodule now uses an SSH URL (so local pushes use the
  developer's own SSH key); runners have no key, so every job rewrites
  `git@github.com:` back to `https://github.com/` before checkout to clone the
  public repository.
- Version bumped to `0.2.0+200002`.

## Platforms and Installation

Only desktop platforms are packaged for release: Windows x64, macOS universal
(Apple Silicon and Intel), and Linux x86_64 (glibc 2.35+).

The installers are **unsigned**:

- **Windows** may warn about an unknown publisher — choose *More info → Run
  anyway*.
- **macOS** — right-click the app and choose *Open*, or allow it under
  *System Settings → Privacy & Security*.
