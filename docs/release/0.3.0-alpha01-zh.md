# SSB Runner 0.3.0-alpha01 更新说明

版本：`0.3.0+300001`

**本版本是 0.3.0 的 alpha 预览版，不是稳定版。** 它带来全新的 Console 界面、四种界面语言、训练暂停/恢复、单条 QSO 语音重放、固定来电台口音，以及重做后的功能键模型。如果你要记录真实比赛，请继续使用 `0.2.1`；本版本用于预览和验证 0.3.0 的改动。

**本版本会改变本地数据格式**：数据库结构升级到 v7，新录制的会话以一条自描述记录头开始。既有历史会原地迁移，但**没有降级路径**。

## 训练暂停与恢复

- **计时的训练局可以暂停，而不必直接放弃。** 暂停会冻结计时、输入区、重试定时器与音频；之后可以恢复，已答过的题目不会丢失。
- **恢复从暂停点继续。** 3-2-1 倒计时（可跳过）结束后直接续播，不回退、不重播。
- **暂停时间不计入练习时间。** 暂停期间计时停止，复盘会分别给出暂停时长与暂停次数，并与有效练习时间分开统计。
- **暂停中的控制台只读。** 暂停期间不接受键入、粘贴和输入法上屏，也不能回看或更正已记录的 QSO；输入区保留原有草稿与外观，不做灰显。
- **结束入口始终可用，退出会明确提示。** 暂停中「结束本局」仍然可见并要求确认；暂停中退出应用会提示本局数据将丢失。暂停/继续只由界面按钮触发，不设键盘快捷键，暂停期间 Enter、Esc、Space、`;` 与 F1–F12 全部被拦截。

## QSO 语音重放与更正

- **更正记录可以按原始语音重放。** 每条 QSO 现在会保存当时的来电台口音与音素目录，更正列表可以直接回放那次交换，而不是重新生成。
- **重放采用 last-wins，且不影响进行中的训练。** 连续点击会打断上一段播放；训练进行中（含暂停）会隐藏所有重放入口。
- **更正对话框改为每行一条 QSO**（每行 64 dp，首屏 6 条，两处错误用 `·` 并列）。没有保存音素信息的老记录显示 `No correct value (legacy)`，且不可重放。

## 固定来电台口音

- **来台语音可以固定为一种口音**——US、UK、JP、RU 或 IN，也可以保留原有的按 DXCC 自动选择（**Auto**），用于针对性的听力练习。
- **口音在每局开始时固定。** 开局时解析为不可变的策略，训练中途修改设置不会影响播放；操作员自己的语音仍使用中性的 Global 音色。
- **成绩会记录口音 id**（老复盘按 `auto` 解析）。本版本刻意不按口音拆分排行榜。

## 全新 Console 界面与多语言

- **桌面界面按 A Console 布局重做**：顶栏、日志卡片、单行输入区、本次练习卡片、赛制规则卡片与四页设置抽屉，取代原来的固定侧栏与数字键盘。
- **明暗两套主题与「晴空」配色**，数据文本使用 Iosevka、中文/日文使用 Noto Sans SC，数字等宽显示，主题模式可持久化。
- **支持英语、简体中文、繁体中文与日语界面**，默认跟随系统语言，也可手动选择并保存。赛制名称与电台缩写不翻译。
- **赛制规则可以在应用内查看**，入口位于赛制设置区标题栏，训练进行中同样可用。
- **最小内容区调整为 1108×772**（macOS 窗口外框约 1108×796），保证在 1.3 倍字号、五种语言下，控制台、本次练习卡片以及三位数的 RST/交换信息格子都完整显示。

## 功能键与快捷键

- **绑定改为以 F1–F12 为中心**，支持显式的 `Spare` 空位，取代原来的动作中心模型；旧绑定在首次启动时一次性迁移。
- **冲突会被自动处理并给出说明。** 同一动作重复绑定时保留 F 号最小者，其余置为 `Spare`；非法动作会被清除；设置列表中已被占用的动作会置灰并显示「已由 Fx 使用」，不再静默拒绝。
- **F12 只清空操作员输入**——不播放音频、不改变状态、不写 QSO、不记事件日志。功能键与固定快捷键只响应裸键，屏蔽 Ctrl/Alt/Meta/Shift。
- **F1 放弃当前 QSO 并把该台重新排入出题队列**，修复了 `HeAskForExchange` 中可能无限循环的一题；F5 在等待序号的状态下也能重发；`;` 在所有适用阶段都能推进，不适用时给出提示。
- **阶段提示只在 Beginner 难度显示**，并且改为写明 Enter/Esc 与界面上的动作（CQ、AGN），不再硬编码 F 键，避免改键后提示指向错误控件。

## 计分与 QSO 处理

- **呼号抄错统一按 QSO 分值的 2 倍罚分**；交换信息错误只判无效（NIL），重复 QSO 不罚分。JIDX 官方没有罚分条款，其 2 倍规则属于训练约定。
- **抄错不再被拒绝，而是照常记录。** 抄错的呼号不会退回可重听状态并丢失 pileup；本局会正常走完，复盘同时显示抄收值与正确值。
- **抄错后交换信息仍可听见**，重试与超时不再落入静音回合。
- **S&P 在第二次回车时校验呼号**；QSO 落库失败也不会再让状态机冻结。
- **DXCC 现在先解析斜杠呼号与精确 token，再走正则**，便携台与特殊事件呼号的前缀判定更准确。

## Windows 安装包

- **Windows 在原有便携 zip 之外新增单文件 Inno Setup 安装包**：按用户安装到 `%LOCALAPPDATA%\Programs`，不需要管理员权限，并写入开始菜单与卸载项。
- CI 会在干净的 Windows runner 上完成安装、启动、卸载并校验产物的端到端测试。

## 底层变更

- Flutter 升级到 3.47.9（Dart 3.13.7），可解析的 Dart 依赖全部升级到最新版本。
- `window_manager` 0.6.0 迁移到原生 API（使用平台原生窗口居中，不再走 legacy 入口）。
- 数据库结构升级到 v7，新增每条 QSO 的口音/音素列；v6 刷新 DXCC 前缀缓存。呼号池与前缀表已重新生成。
- 草稿 Release 任务改为只在推送标签时运行，手动全平台打包不会因缺少 tag 而失败。

## 已知限制（Alpha）

- **仅供预览。** 请把 0.3.0-alpha01 当作测试版本；真实比赛记录请使用 `0.2.1`。
- **不可降级。** 数据库已迁移到 v7。`0.2.x` 版本可能无法打开本 alpha 写出的数据库，切回旧版前请先导出/备份 QSO 历史。
- **旧录像无法证明归属。** 会话重放依赖本版本新增的开局记录头。由 `0.2.1` 或更早版本录制的待重放会话会被拒绝，并改为按当前设置开局。
- **没有在线排行榜。** 设计文档中的分数上传与服务端重放校验不在本 alpha 范围内。
- **安装包未签名**（见下文）。
- Linux 安装包要求 glibc 2.35 或更高版本。

## 平台与安装

仅打包桌面平台：Windows x64、macOS universal（Apple Silicon 与 Intel）、Linux x86_64（glibc 2.35+）。

安装包**未签名**：

- **Windows** 可能提示未知发布者 — 选择 *更多信息 → 仍要运行*。
- **macOS** — 右键点击应用并选择 *打开*，或在 *系统设置 → 隐私与安全性* 中允许。
