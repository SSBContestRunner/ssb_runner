# SSB Runner 0.3.0-alpha01 Release Notes

Version: `0.3.0+300001`

**This is an alpha preview of 0.3.0, not a stable release.** It ships the new
console UI, four interface languages, practice pause/resume, per-QSO voice
replay, a fixed incoming accent and a reworked function-key model. Use `0.2.1`
if you are logging a real contest; this build is meant for previewing and
testing the 0.3.0 changes.

**This release does change local data formats**: the database schema moves to
v7 and new recordings start with a self-describing header. Existing history is
migrated in place, but there is no downgrade path.

## Practice Pause and Resume

- **A timed run can now be paused instead of abandoned.** Pausing freezes the
  clock, the input area, retry timers and audio in place; the session can be
  resumed later without losing the questions already answered.
- **Resume continues from the pause point.** A 3-2-1 countdown (skippable)
  leads back into the run; nothing is rewound or replayed.
- **Pause time is not practice time.** The elapsed clock stops while paused and
  the review reports paused duration and pause count separately from the
  effective practice time.
- **The paused console is read-only.** Typing, paste and IME input are blocked
  while paused, and recorded QSOs cannot be reviewed or corrected. The input
  keeps its draft and appearance instead of going grey.
- **Ending is always available, and leaving is explicit.** "End session" stays
  visible while paused and asks for confirmation; quitting the app while paused
  warns that the current run will be lost. Pause and resume are driven only by
  the on-screen button — there are no keyboard shortcuts, and Enter, Esc, Space,
  `;` and F1–F12 are swallowed while paused.

## QSO Voice Replay and Corrections

- **Corrected QSOs can be replayed with their original audio.** Each logged
  QSO now stores the accent and phonetic directories it was sent with, so the
  correction list can replay the exact exchange instead of regenerating it.
- **Replay is last-wins and never disturbs a run.** Repeated clicks interrupt
  the previous clip; all replay entry points are hidden while a run is
  running or paused.
- **The correction dialog is one row per QSO** (64 dp, six rows visible, a
  `·`-separated pair for two errors). Legacy QSOs without stored phonetics show
  `No correct value (legacy)` and cannot be replayed.

## Fixed Incoming Accent

- **Incoming audio can be pinned to one accent** — US, UK, JP, RU or IN — or
  left on the existing DXCC-based **Auto** behaviour, for targeted listening
  practice.
- **The choice is fixed per session.** It is resolved into an immutable policy
  when the run starts, so changing the setting mid-session cannot alter playback.
  The operator's own voice remains the neutral Global voice.
- **Results record the accent id** (older reviews decode as `auto`). The
  leaderboard is deliberately not split by accent in this version.

## New Console UI and Localization

- **The desktop UI is rebuilt to the A Console layout**: top bar, log card,
  single-row console, session card, contest rules card and a four-tab settings
  drawer, replacing the fixed sidebar and keypad.
- **Light and dark themes with the "clear sky" palette**, Iosevka for data and
  Noto Sans SC for Chinese/Japanese, with tabular numerals and theme mode
  persistence.
- **English, Simplified Chinese, Traditional Chinese and Japanese UI**,
  following the system language by default with a persisted manual override.
  Contest names and radio abbreviations stay untranslated.
- **Contest rules are available in-app** from the Contest settings section
  header, while a run is in progress.
- **The minimum window is 1108×796**, sized so the console, session card and
  three-digit RST/exchange cells stay whole at a 1.3× text scale in every
  language.

## Function Keys and Shortcuts

- **Bindings are key-centric F1–F12** with explicit `Spare` slots, replacing the
  old action-centric model; existing bindings are migrated once on first launch.
- **Conflicts are resolved and explained.** A duplicate action keeps the lowest
  F key and the rest become `Spare`; invalid actions are cleared; occupied
  actions are greyed out in the settings list with an "already used by Fx"
  note instead of being silently rejected.
- **F12 wipes the operator input only** — no audio, no state change, no QSO
  write, no log entry. Function keys and the fixed shortcuts accept bare keys
  only and ignore Ctrl/Alt/Meta/Shift.
- **F1 abandons an in-flight QSO and requeues the station**, fixing the round
  that could loop forever in `HeAskForExchange`; F5 repeats from the
  serial-waiting states; `;` advances every phase it is valid in and shows a
  hint when it is not.
- **Phase hints are shown at Beginner difficulty only** and now name Enter/Esc
  plus the on-screen actions (CQ, AGN) instead of hardcoded F keys, so a
  rebound key never makes the hint point at the wrong control.

## Scoring and QSO Handling

- **A busted callsign is charged 2× its QSO point value** in every contest;
  a wrong exchange is NIL only. Duplicates remain free. JIDX has no official
  penalty clause, so its 2× is a training convention.
- **Wrong copies are logged instead of rejected.** A mis-copied call no longer
  returns to the listening state and drops the pile-up; the QSO runs to
  completion and the review shows both the copied and the correct values.
- **A wrong copy keeps the exchange audible**, so retries and timeouts no longer
  fall into a silent round.
- **S&P validates the callsign on the second Enter**, and a failed QSO write no
  longer freezes the state machine.
- **DXCC slash calls and exact tokens resolve before the regex**, improving
  prefix resolution for portable and special-event callsigns.

## Windows Installer

- **Windows now also ships a single-file Inno Setup installer** with the
  existing portable zip. It installs per user under `%LOCALAPPDATA%\Programs`,
  needs no administrator rights, and creates Start menu and uninstall entries.
- CI installs, launches, uninstalls and verifies the installer on a clean
  Windows runner.

## Under the Hood

- Flutter upgraded to 3.47.9 (Dart 3.13.7) and all resolvable Dart
  dependencies to their latest versions.
- `window_manager` 0.6.0 migrated to its native API (native window centering,
  no legacy entry points).
- Database schema v7 adds the per-QSO accent/phonetic columns; v6 refreshes the
  DXCC prefix cache. The callsign pool and prefix table were regenerated.
- The draft-release job now runs only on tag pushes, so manual all-platform
  package runs do not fail on a missing tag.

## Known Limitations (Alpha)

- **Preview only.** Treat 0.3.0-alpha01 as a test build; use `0.2.1` for real
  contest logging.
- **No downgrade.** The database is migrated to schema v7. A `0.2.x` build may
  refuse to open a database written by this alpha, and QSOs logged here should
  be exported/backed up before switching back.
- **Old recordings cannot prove ownership.** Session replay requires the
  run-start header added in this version. A pending replay armed from a
  `0.2.1` or earlier recording is refused and the run starts from the current
  settings.
- **No online leaderboard.** Score submission and the server-side replay
  verification described in the design notes are not part of this alpha.
- **Installers are unsigned** (see below).
- Linux packages require glibc 2.35 or newer.

## Platforms and Installation

Only desktop platforms are packaged for release: Windows x64, macOS universal
(Apple Silicon and Intel), and Linux x86_64 (glibc 2.35+).

The installers are **unsigned**:

- **Windows** may warn about an unknown publisher — choose *More info → Run
  anyway*.
- **macOS** — right-click the app and choose *Open*, or allow it under
  *System Settings → Privacy & Security*.
