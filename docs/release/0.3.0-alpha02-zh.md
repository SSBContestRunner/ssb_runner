# SSB Runner 0.3.0-alpha02 更新说明

版本：`0.3.0+300002`

**本版本仍是 0.3.0 的 alpha 预览版，不是稳定版。** 它修复 `0.3.0-alpha01` 暴露的启动白屏/启动慢与窗口尺寸问题，新增 Windows 启动时间线诊断，并为发布资产新增 SHA-256 校验。**本版本没有数据库结构或事件日志格式变更**；如果要记录真实比赛，请继续使用 `0.2.1`。

从 `0.3.0-alpha01` 升级可以直接覆盖安装：数据库、设置与训练记录都会保留。

## 启动：首帧不再等待磁盘与平台通道

- **窗口一出现就是加载界面。** `main()` 不再在首帧前读文件或等待 `PackageInfo`；日志、偏好设置、数据库、DXCC 前缀、呼号表与音频初始化全部移到首帧之后，启动时不再先看到空窗或白屏。
- **首帧前的日志不会丢失。** 这段日志先写入内存缓冲，文件日志就绪后按原始时间戳回放，启动诊断仍然完整。
- **启动路径上的同步文件操作改为异步**，可执行目录的清单探测移入独立 isolate，避免杀毒软件逐个扫描时卡住界面。
- **启动诊断更细。** 日志记录首帧可见时间（相对 `main()`）、日志落盘的回放条数，以及窗口外框/内容区/最小尺寸与耗时，便于判断剩余延迟是否还在 Dart 侧。

## Windows 启动时间线诊断

- **启动全过程可追溯。** Windows runner 原生记录「进程启动 → `wWinMain` → Dart `main` → 首帧 → 窗口显示」的时间线，应用启动后与 Dart 启动阶段合并成一条 `boot timeline` 记录写入 `latest.log`，临时文件随即删除。
- **启动卡住能被识别。** 10 秒内未显示窗口时写入 `state=timeout` 并标明最后完成的阶段；Dart UI isolate 心跳中断超过 10 秒时写入 `dart_stalled`，标明停住的阶段与步骤。诊断摘要新增启动时间线一节。
- **正常启动没有额外负担。** UI isolate 每 2 秒上报一次心跳，只写原生内存中的原子变量、不写盘不打日志，进入 `ready` 后停止；正常冷启动只多一条 `boot timeline` 记录。

## 窗口尺寸：以内容区为唯一契约

- **最小内容区为 1108×772**（macOS 外框约 1108×796）。布局验收标准从此按内容区计算，不再按窗口外框。
- **修复 Windows 内容区偏小。** 此前按外框 1108×796 配置，Windows 的标题栏与边框会吃掉约 16×39，实际内容区低于验收值，最小窗口下可能出现裁切或滚动。现在用运行时测得的非客户区反推外框最小值，三个平台得到一致的内容区。
- **首帧就是最终尺寸。** Windows、macOS、Linux 的原生 runner 直接以 1108×772 内容区创建窗口，不再先按 1280×720 或 800×600 绘制再调整大小，启动时少一次 surface 重建。
- **记住上次的窗口尺寸。** 正常状态下的内容区尺寸会被保存并在下次启动恢复；最大化、全屏与最小化的尺寸不参与保存，恢复值会被限制在主屏可用区域内。退出前尚未落盘的调整也会补写。

## 发布资产校验

- **每个 Release 新增 `SHA256SUMS.txt`**，并在发布说明顶部列出同样的 SHA-256 指纹。下载后可执行 `sha256sum -c SHA256SUMS.txt`（Linux）、`shasum -a 256 -c SHA256SUMS.txt`（macOS）或 `Get-FileHash -Algorithm SHA256`（Windows）核对。
- 指纹只证明下载到的文件与发布时一致，**不等同于代码签名**，不能证明构建者身份。README 已补充对应说明。

## 已知限制（Alpha）

- **仅供预览。** 请把 0.3.0-alpha02 当作测试版本；真实比赛记录请使用 `0.2.1`。
- **不可降级。** 数据库已迁移到 v7。`0.2.x` 版本可能无法打开本 alpha 写出的数据库，切回旧版前请先导出/备份 QSO 历史。
- **旧录像无法证明归属。** 会话重放依赖 0.3.0 新增的开局记录头。由 `0.2.1` 或更早版本录制的待重放会话会被拒绝，并改为按当前设置开局。
- **没有在线排行榜。** 设计文档中的分数上传与服务端重放校验不在本 alpha 范围内。
- **安装包未签名**（见下文）。
- Linux 安装包要求 glibc 2.35 或更高版本。

## 平台与安装

仅打包桌面平台：Windows x64、macOS universal（Apple Silicon 与 Intel）、Linux x86_64（glibc 2.35+）。

安装包**未签名**：

- **Windows** 可能提示未知发布者 — 选择 *更多信息 → 仍要运行*。
- **macOS** — 右键点击应用并选择 *打开*，或在 *系统设置 → 隐私与安全性* 中允许。
