# SSB Runner 0.2.0 更新说明

版本：`0.2.0+200001`

> **升级前请先阅读「重要变更」一节**：本次更换了应用标识，安装包的数据（设置、日志）存放位置发生变化，且旧的偏好设置不会自动迁移。

## 重要变更（破坏性）

### 1. 应用标识更换，数据目录随之变化

应用标识由 `com.example.*` 统一更换为 `com.ssbrunner.app`（Windows 为 `com.ssbrunner`）。该标识决定了系统为应用分配的私有数据目录，因此升级后应用会在**新目录**中工作，且**不会**自动搬迁旧目录里的内容。

需要你手动处理的情况：

- **设置会重置。** 比赛选择、时长、音标类型、功能键、练习种子等偏好项存储在由标识决定的系统位置，升级后将恢复默认值，需要重新设置一遍。
- **数据库（QSO 历史）会保留。** 数据库保存在「文档」目录下（macOS 为 `~/Documents/ssb_runner/db`，Windows / Linux 为 `文档/ssb_runner/db`），该位置不受标识影响，**历史 QSO 记录会保留**；仅偏好设置会重置。
- **旧文件不会自动删除**，仍留在旧路径下，可自行确认后清理。

### 2. 日志位置变化

日志不再写入「文档」目录，改为写入应用数据目录下的 `log/`：

| 平台 | 新日志路径 |
| --- | --- |
| Windows | `%APPDATA%\com.ssbrunner\ssb_runner\log` |
| macOS | `~/Library/Application Support/com.ssbrunner.app/log` |
| Linux | `~/.local/share/com.ssbrunner.app/log` |

旧位置（`文档/ssb_runner/log`）不再有日志。若以前靠该目录排查问题，请注意路径已变。

配套新增了两个入口，无需再手动找目录：

- **设置 → Diagnostics → Export logs**：将日志打包为 zip 保存到「文档」目录，并把路径复制到剪贴板。
- **设置 → Diagnostics → Copy diagnostics**：直接把环境摘要复制到剪贴板，反馈问题时粘贴即可。

日志本身也有改进：5 MB 轮转、保留最近 10 份；崩溃时会附带最近的运行缓冲；`verbose logging` 开关可即时生效，方便临时抓取详细日志。

### 3. 数据库结构升级（自动）

数据库版本由 1 升级到 3，升级时自动执行，**不会清除已有的 QSO 记录**。其中一项是重建前缀缓存，因此升级后**首次启动会重新解析 DXCC 数据，可能比平时稍慢一点**，之后恢复正常。

## 新增功能

- **比赛训练模板**：新增 CQ WPX SSB、CQ WW SSB、ARRL DX SSB、IARU HF SSB、JIDX SSB。注意这些是**单波段训练档**，用于练习，并非 Cabrillo 认证计分。
- **三种训练模式**：Run（依次应答）、S&P（逐台搜索）、Pile-up（多台重叠呼叫中挑选目标）。
- **三档难度**：Beginner / Standard / Advanced，影响语速、接收机底噪强度、静电（QRN）爆点、信号内信噪比噪声与 QSB 衰落深度。
- **接收机底噪**：在两次信号之间的静默期持续播放符合 SSB 通带的嘶声（含静电 QRN 爆点），而不是只把一次性噪声叠加在语音上；Pile-up 模式下多台呼叫采用正确混音，目标台不会被过度衰减。
- **可复现的练习种子**：题目种子与音频种子相互独立，可分别锁定、复制/粘贴；每局结束可在复盘浮层一键「重放本局」，用相同种子完整重现。
- **赛后复盘**：显示 QSO 数、准确率、速率、得分，以及呼号/交换错误分类；并保留最近 30 局的会话历史，可回看与重放。
- **可自定义 F1–F8 功能键**，改键即时生效，并校验按键不重复。
- **接收音量滑条**（20%–120%），仅作用于对方台，你自己的 CQ 与发报保持清晰。
- **按比赛配置我方 Exchange**：不同比赛（如分区、州/省、序列号、日本县等）可分别填写，开赛前会校验完整性。
- **诊断面板**：Verbose logging、导出日志、复制诊断。

## 修复与改进

- 修复正式版（release）构建下**应用日志不写入文件**的问题（日志过滤条件错误）。
- 修复 Windows 上**没有日志文件**的问题。
- 修复开局阶段速率显示严重偏低的问题，改为最近 5 个 QSO 的滚动速率；无 QSO 时显示 `--- QSOs/h`。
- 修复键盘速查表在深色主题下不可读的问题。
- 修复过长呼号或更正内容会撑破结果表的问题，现在改为省略号显示。
- 窗口**现在可以缩放**，最小尺寸 1024×650。
- 启动或音频初始化失败时应用仍可继续启动，并显示错误页，提供复制诊断/导出日志。
- 未捕获的异步异常现在会被记录到日志中。

## 平台与安装

正式发布仅包含桌面平台：Windows x64、macOS 通用（Apple Silicon 与 Intel）、Linux x86_64（glibc 2.35+）。
