# SSB Runner 0.3.0-alpha04 Release Notes

Version: `0.3.0+300004`

**This is still an alpha preview of 0.3.0, not a stable release.** This build
only changes the Windows installer; **the application code, database schema and
event-log format are unchanged**, so training history and settings survive the
upgrade as-is. Use `0.2.1` if you are logging a real contest.

Upgrading from `0.3.0-alpha03` is a plain over-install.

## Windows installer: four installer languages

- **The setup wizard is available in English, Simplified Chinese, Traditional
  Chinese and Japanese**, matched automatically from the system language; the
  language dialog only appears when nothing matches.
- **Fixed "Chinese configured, English produced".** The config declared
  `locales: [en, zh]`, but the packager's built-in template only looked for
  language files under Inno Setup's `Languages\` directory. Inno Setup 6.x
  ships Simplified and Traditional Chinese as unofficial translations under
  `Languages\Unofficial\`, so they were **silently skipped** and the setup was
  English-only.
- **The language list now lives solely in the installer script.** Windows
  packaging uses a custom Inno Setup template whose `[Languages]` section is
  fixed to the four languages above; a wrong `.isl` path is now a compile
  error instead of a silent fallback. The trade-off is that a new in-app
  language must be added to that template too.
- **Language files are checked at build time.** CI asserts that all four `.isl`
  files exist before packaging, force-reinstalls Inno Setup once if any are
  missing, and fails with an explicit message if they are still missing.

## Windows installer: "launch at startup" is gone

- **The setup wizard no longer offers a "launch at startup" checkbox**, and a
  fresh install no longer writes `SSB Runner.lnk` into the Startup folder.
- Previously `launch_at_startup: false` could only leave the checkbox
  unchecked: the built-in template emitted the task and the Startup shortcut
  unconditionally, so replacing the template was the only way to remove them.
- The "Additional tasks" page now only offers "Create a desktop icon", which
  is still unchecked by default.
- **Users who installed an older alpha and enabled startup are not cleaned
  up.** Delete that shortcut manually, or uninstall and reinstall.

## Windows installer: the wizard shows the app logo

- The upper-right corner of the wizard now shows the app logo (three sizes,
  58/116/174, with Inno picking the closest to the current DPI scale) instead
  of Inno Setup's stock placeholder image.

## Release process

- **The SHA-256 fingerprint section of the release notes is now in English**
  to match the public release page; the verification steps and the source of
  the fingerprints are unchanged.

## Known Limitations (Alpha)

- **Preview only.** Treat 0.3.0-alpha04 as a test build; use `0.2.1` for real
  contest logging.
- **No downgrade.** The database is migrated to schema v7. A `0.2.x` build may
  refuse to open a database written by this alpha, and QSOs logged here should
  be exported/backed up before switching back.
- **Old recordings cannot prove ownership.** Session replay requires the
  run-start header added in 0.3.0. A pending replay armed from a `0.2.1` or
  earlier recording is refused and the run starts from the current settings.
- **No online leaderboard.** Score submission and the server-side replay
  verification described in the design notes are not part of this alpha.
- **Installers are unsigned** (see below).
- Linux packages require glibc 2.35 or newer.

## Platforms and Installation

Only desktop platforms are packaged for release: Windows x64, macOS universal
(Apple Silicon and Intel), and Linux x86_64 (glibc 2.35+).

The installers are **unsigned**:

- **Windows** may warn about an unknown publisher — choose *More info → Run
  anyway*.
- **macOS** — right-click the app and choose *Open*, or allow it under
  *System Settings → Privacy & Security*.
