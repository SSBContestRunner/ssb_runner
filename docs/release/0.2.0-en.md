# SSB Runner 0.2.0 Release Notes

Version: `0.2.0+200001`

> **Please read "Important Changes" before upgrading.** This release changes the
> application identifier, which moves where the app stores its data (settings and
> logs). Existing preferences are **not** migrated automatically.

## Important Changes (Breaking)

### 1. New application identifier moves the data directory

The application identifier changed from `com.example.*` to `com.ssbrunner.app`
(`com.ssbrunner` on Windows). The OS uses this identifier to assign the app its
private data directory, so after upgrading the app works in a **new directory**
and does **not** move anything from the old one.

What this means for you:

- **Settings are reset.** Contest selection, duration, phonic type, function-key
  bindings, practice seeds, and other preferences live in an identifier-keyed
  system location. After upgrading they return to their defaults and must be set
  again.
- **Your database (QSO history) is preserved.** The database lives in your
  Documents folder (`~/Documents/ssb_runner/db` on macOS,
  `Documents/ssb_runner/db` on Windows/Linux), which the identifier does not
  affect, so your **existing QSO history is preserved**. Only preferences are
  reset.
- **Old files are not deleted.** They remain in the old location; check and clean
  them up yourself if you wish.

### 2. Log files moved

Logs are no longer written to the Documents folder. They now live under `log/`
in the application data directory:

| Platform | New log path |
| --- | --- |
| Windows | `%APPDATA%\com.ssbrunner\ssb_runner\log` |
| macOS | `~/Library/Application Support/com.ssbrunner.app/log` |
| Linux | `~/.local/share/com.ssbrunner.app/log` |

The old location (`Documents/ssb_runner/log`) no longer contains logs. If you
relied on that folder for troubleshooting, note the new path.

Two new entry points mean you never have to locate the folder by hand:

- **Settings → Diagnostics → Export logs** — zips the logs into your Documents
  folder and copies the path to the clipboard.
- **Settings → Diagnostics → Copy diagnostics** — copies the environment summary
  straight to the clipboard for pasting into a bug report.

Logging itself also improved: 5 MB rotation with the last 10 files kept, a
recent-run buffer attached to crashes, and a `verbose logging` toggle that takes
effect immediately for capturing detailed logs on demand.

### 3. Database schema upgrade (automatic)

The database version is upgraded from 1 to 3 automatically. It **does not delete
your existing QSO records**. One step rebuilds the prefix cache, so **the first
launch after upgrading re-parses the DXCC data and may be slightly slower than
usual**; it returns to normal afterwards.

## New Features

- **Contest training templates**: CQ WPX SSB, CQ WW SSB, ARRL DX SSB, IARU HF
  SSB, and JIDX SSB. These are **single-band training profiles**, not Cabrillo
  certification scoring.
- **Three training modes**: Run (callers answer in sequence), S&P (find and work
  one station at a time), and Pile-up (pick the target from overlapping callers).
- **Three difficulty levels**: Beginner / Standard / Advanced, controlling
  playback speed, receiver noise-bed level, static (QRN) bursts, in-signal SNR
  noise, and QSB fading depth.
- **Receiver noise bed**: continuous SSB-passband hiss (with static QRN bursts)
  during the silence between signals, instead of one-off noise layered onto
  speech; pile-up callers are mixed correctly so the target is not
  over-attenuated.
- **Reproducible practice seeds**: independent question and audio seeds that can
  be locked, copied, and pasted separately; replay a whole session from the
  review overlay using the same seed.
- **Post-session review**: QSO count, accuracy, rate, score, and call/exchange
  error categories, plus a history of the last 30 sessions that can be reviewed
  and replayed.
- **Customizable F1–F8 function keys**, applied immediately, with duplicate-key
  validation.
- **Incoming-station audio volume slider** (20%–120%). It affects only the other
  station — your own CQ and sending stay clear.
- **Per-contest exchange configuration**: fill in your exchange for each contest
  (zone, state/province, serial, Japanese prefecture, and so on), validated for
  completeness before a run starts.
- **Diagnostics panel**: verbose logging, export logs, and copy diagnostics.

## Fixes and Improvements

- Fixed **application logs not being written to file** in release builds (an
  incorrect log filter).
- Fixed **no log files on Windows**.
- Fixed the rate display reading far too low at the start of a run; it now shows
  a rolling five-QSO rate and `--- QSOs/h` when there are no QSOs yet.
- Fixed the keyboard reference being unreadable in dark theme.
- Fixed long callsigns or corrections overflowing the result table; they are now
  ellipsised.
- The window is **now resizable**, with a minimum size of 1024×650.
- The app still starts when startup or audio initialization fails, and shows an
  error page with copy-diagnostics / export-logs actions.
- Uncaught asynchronous errors are now recorded in the log.

## Platforms and Installation

Only desktop platforms are packaged for release: Windows x64, macOS universal
(Apple Silicon and Intel), and Linux x86_64 (glibc 2.35+).

The installers are **unsigned**:

- **Windows** may warn about an unknown publisher — choose *More info → Run
  anyway*.
- **macOS** — right-click the app and choose *Open*, or allow it under
  *System Settings → Privacy & Security*.
