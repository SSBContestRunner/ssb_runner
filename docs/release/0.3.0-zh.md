# SSB Runner 0.3.0 更新说明

版本：`0.3.0+300009`

这是自 `0.2.1` 之后的第一个稳定版。它带来 A Console 界面、四种界面语言、训练暂停/恢复、单条 QSO 语音重放、固定来电台口音、重做后的功能键模型，以及"听不到呼叫音频"时的输出监测提醒。Windows 从仅提供便携 zip 改为提供单文件安装包，同时明确了真实的系统版本底线，并修复了 0.3.0 预览阶段暴露的启动、退出与安装器问题。

**本版本会改变本地数据格式**：数据库升级到 v7，新录制的会话以一条自描述的开局记录头开始。既有 QSO 历史会原地迁移，但**没有降级路径**：`0.2.x` 版本可能无法打开由 `0.3.0` 写出的数据库。

从 `0.2.1` 升级会保留设置和训练记录。从 0.3.0 预览版升级时，如果当前安装来自 `0.3.0-alpha07` 或之后的构建，直接覆盖安装即可；仍在使用 `0.3.0-alpha06` 或更早版本时请先卸载，因为 Windows 默认安装目录已从 `Programs\SSB Runner` 改为 `Programs\SSB_Runner`。

## 全新 Console 界面与多语言

- **桌面界面按 A Console 布局重做**：顶栏、日志卡片、单行输入区、本次练习卡片、赛制规则卡片与四页设置抽屉，取代原来的固定侧栏与数字键盘。
- **明暗两套主题使用「晴空」配色**，数据文本使用 Iosevka、中文/日文使用 Noto Sans SC，数字等宽显示，主题选择可持久化。界面用到的字形全部随包提供，不再按字回退到平台字体、出现不同字重。
- **支持英语、简体中文、繁体中文与日语界面**，默认跟随系统语言，也可手动选择并保存。赛制名称与电台缩写不翻译。
- **赛制规则可以在应用内查看**，入口位于赛制设置区标题栏，训练进行中同样可用。
- **三个桌面平台的最小内容区域统一为 1108×772**：原生启动器直接按该尺寸创建窗口，并会记住上次正常状态的窗口大小。
- **开始前的检查会说明缺什么**：每项阻塞设置都列出字段名与抽屉路径，点击即可打开对应设置页并聚焦字段；本次练习卡片上的就绪/运行中/待处理状态标签也能一眼看出当前状态。

## 训练：暂停、恢复与重放

- **计时的训练局可以暂停，而不必直接放弃。** 暂停会冻结计时、输入区、重试定时器与音频；3-2-1 倒计时（可跳过）后从暂停点继续，已答过的题目不会丢失。
- **暂停时间不计入练习时间。** 复盘会分别给出暂停时长与暂停次数，并与有效练习时间分开统计。
- **暂停中的控制台只读。** 暂停期间不接受键入、粘贴和输入法上屏，草稿保留；「结束本局」仍然可见并要求确认。Enter、Esc、Space、`;`、F1–F12 与退出应用都有明确处理，不会静默丢掉暂停中的训练。
- **更正记录可以按原始语音重放。** 每条 QSO 现在会保存当时的来电台口音与音素目录，更正列表可以直接回放那次交换，而不是重新生成。没有这些信息的老记录会被标记且不可重放。
- **重放采用 last-wins，且不影响进行中的训练。** 连续点击会打断上一段播放；训练进行中（含暂停）会隐藏所有重放入口。
- **会话重放会校验赛制归属。** 待重放会话会保存录制时的赛制/模式/难度/种子快照；缺少新的开局记录头或与当前设置不符的录像会被拒绝，并按当前设置开局。

## 听力练习与计分

- **来台语音可以固定为一种口音**——US、UK、JP、RU 或 IN，也可以保留按 DXCC 自动选择的 **Auto**。选择在开局时解析为不可变策略，训练中途修改设置不会影响播放；操作员自己的语音仍使用中性的 Global 音色。
- **呼号抄错统一按 QSO 分值的 2 倍罚分**；交换信息错误只判无效（NIL），重复 QSO 不罚分。JIDX 官方没有罚分条款，其 2 倍规则属于训练约定。
- **抄错不再被拒绝，而是照常记录。** 抄错的呼号不会丢失 pileup 或让本题静音：QSO 正常走完，复盘同时显示抄收值与正确值，重试与超时仍会正常出声。
- **`;` 在所有适用阶段都能推进**，不适用时给出提示；F5 在等待序号的状态下也能重发。
- **DXCC 先解析斜杠呼号与精确 token，再走正则**，便携台与特殊事件呼号的前缀判定更准确。

## 功能键

- **绑定改为以 F1–F12 为中心**，支持显式的 `Spare` 空位，取代原来的动作中心模型；旧绑定在首次启动时一次性迁移。
- **冲突会被自动处理并给出说明。** 同一动作重复绑定时保留 F 号最小者，其余置为 `Spare`；非法动作会被清除；已占用的动作会置灰并显示「已由 Fx 使用」。
- **F12 只清空操作员输入**——不播放音频、不改变状态、不写 QSO、不记事件日志。功能键与固定快捷键只响应裸键，屏蔽 Ctrl/Alt/Meta/Shift。
- **F1 放弃当前 QSO 并把该台重新排入出题队列**，修复了 `HeAskForExchange` 中可能无限循环的一题。
- **阶段提示只在 Beginner 难度显示**，并且写明 Enter/Esc 与界面上的动作，不再硬编码 F 键，避免改键后提示指向错误控件。

## 音频输出监测

- **常驻监测器覆盖整条输出链路**：macOS 使用 CoreAudio、Windows 使用 WASAPI、Linux 使用 `pactl`/`wpctl`，同时检查 SoLoud 引擎状态。顶栏徽标只在出现问题时显示。
- **识别四类异常**：输出被静音、音量低于 10 %、没有输出设备、引擎未能初始化。低音量与静音使用不同图标；读不到的状态保持「未知」，不会被误判为正常。
- **提醒经过防抖**：硬故障立即提示；进入低音量以及从任意告警恢复需要 600 ms 静默窗口或连续两次采样，拖动音量条时徽标不会闪烁。采样运行在 idle 优先级，系统事件采样每 300 ms 最多一次。
- **开始训练前的预检会给出原因、当前音量与设备名**，提供「重新检查」、系统声音设置入口与「仍然开始」；只有低音量可以被永久忽略。
- **进行中的训练不会被打断**：故障以非模态提示出现，每种原因每局一次，不抢焦点也不暂停计时；开始按钮也防止双击启动两局。
- **设置中新增「播放测试音」**，按录音自身音量播放，加载失败时回退到生成音，并明确显示播放中/播放失败。
- `SSB_RUNNER_DISABLE_AUDIO=1` 可在排障时关闭监测器。

## 启动、退出与诊断

- **窗口出现即进入加载界面。** `main()` 在首帧之前不再读文件或等待平台通道；日志、偏好设置、数据库、DXCC 前缀与音频都在首帧之后启动。首帧前的日志先缓存在内存中，之后按原时间戳回放到日志文件。
- **Windows 会记录完整启动时间线**：进程启动 → `wWinMain` → Dart `main` → 首帧 → 窗口显示，附带 10 秒超时与 UI isolate 心跳。卡住时会把停在哪一步写入 `latest.log` 与诊断摘要。
- **MSVC 运行库改由构建工具链提供。** 仓库里随包携带的旧版本会让预览版在 Windows 首帧前崩溃；现在打包时会校验运行库版本与编译器版本一致。
- **关闭窗口不再留下后台进程。** 退出路径会等待进行中的音频初始化、始终释放引擎，并且只在状态确定时应答关闭请求；原生 5 秒看门狗兜住 `ExitProcess` 自身的卡死。
- **每个版本都会发布 `SHA256SUMS.txt`**，并把相同指纹放在发布说明开头。指纹只能证明下载到的字节与发布时一致，不等于代码签名。

## Windows 安装包

- **Windows 在便携 zip 之外新增单文件 Inno Setup 安装包**：按用户安装到 `%LOCALAPPDATA%\Programs\SSB_Runner`，不需要管理员权限，并写入开始菜单与卸载项。
- **安装向导提供英语、简体中文、繁体中文与日语**，自动匹配系统语言，显示应用徽标，并移除「开机启动」选项及对应快捷方式。
- **覆盖安装会说明自己在覆盖什么。** 只有检测到旧安装时才出现该页面，显示已安装版本 → 本次安装包版本、真实的目标目录，以及"设置与训练记录保存在用户数据目录，不会被删除"。同版本重装会明确说明即使版本相同也会重新写入并覆盖已安装文件。静默安装路径不受影响。
- **降级被拒绝**：旧安装包无法在交互或静默模式下覆盖较新的安装，也没有「强制继续」，因为数据库迁移只向前进行。
- **覆盖安装不再新旧文件混装**：DLL 与 `data\` 会在写入新文件前删除，`db\` 与 `log\` 被明确排除，训练记录与日志不会被触碰。

## 底层变更

- Flutter 升级到 3.47.9（Dart 3.13.7），可解析的依赖升级到最新版本；`window_manager` 0.6 迁移到原生 API。
- 数据库结构升级到 v7，新增每条 QSO 的口音/音素列；v6 刷新 DXCC 前缀缓存。呼号池与前缀表已重新生成。
- CI 现在声明并校验 Windows 10 1607、macOS 13 与 glibc 2.35 三个底线，包括通过导入表检查防止依赖升级抬高 Windows 要求。
- 打包静态契约与三平台 dry run 让 ISCC、dpkg-deb、appimagetool、appdmg 在合并前就真正执行，而不再等到打 tag；三个平台的原生 runner 都会在 PR 上编译，且只重试瞬时打包失败。
- `flutter analyze --fatal-infos` 将 info 级提示纳入门禁，测试套件也不再输出 drift 的多实例警告。

## 已知限制

- **不可降级。** 数据库已迁移到 v7；切回 `0.2.x` 前请先备份或导出 QSO 历史。
- **旧录像无法证明归属。** 由 `0.2.1` 或更早版本录制的待重放会话会被拒绝，并改为按当前设置开局。
- **没有在线排行榜。** 设计文档中的分数上传与服务端重放校验不在本版本范围内。
- **支持的系统**：Windows 10 版本 1607（Build 14393）或更高版本；macOS 13 Ventura 或更高版本；glibc 2.35 或更高的 Linux。不支持 Windows 10 1507/1511、macOS 12 与更旧的发行版；1607 上进程是 DPI 不感知的，125 %/150 % 缩放下界面会被位图拉伸（PerMonitor 缩放从 1703 开始）。
- **音频提示依赖平台探针。** 若系统既读不到音量、静音也读不到默认设备，徽标按设计保持沉默。Linux 需要 `pactl`（PulseAudio/PipeWire）或 `wpctl`；macOS 只检查默认输出设备。Intel 版 macOS 支持为尽力而为。
- **安装包未签名**（见下文）。

## 平台与安装

仅打包桌面平台：Windows x64、macOS universal（Apple Silicon 与 Intel）、Linux x86_64。

- **Windows** — `*windows-setup.exe`（纯 per-user 安装，不弹 UAC；低于 Windows 10 1607 会拒绝安装）或 `*windows.zip`。
- **macOS** — `*macos.dmg`，把 **SSB Runner.app** 拖入 *Applications*。
- **Linux** — `.deb`、`.AppImage` 与 `.zip`，三者都要求 glibc 2.35+。AppImage 挂载需要 FUSE 2，也可用 `--appimage-extract-and-run` 运行。

安装包**未签名**：

- **Windows** 可能提示未知发布者 — 选择 *更多信息 → 仍要运行*。
- **macOS** — 右键点击应用并选择 *打开*，或在 *系统设置 → 隐私与安全性* 中允许。
