# v0.3.0 多语言支持实现计划

## 1. 目标与范围

为 v0.3.0 增加应用内多语言支持，首批语言：

| 语言 | Locale | ARB 文件 |
| --- | --- | --- |
| 英文 | `en` | `lib/l10n/app_en.arb`（模板） |
| 简体中文 | `zh_Hans` | `lib/l10n/app_zh_Hans.arb` |
| 繁体中文 | `zh_Hant` | `lib/l10n/app_zh_Hant.arb` |
| 日文 | `ja` | `lib/l10n/app_ja.arb` |

行为约定（已与用户确认）：

1. 默认**跟随系统**；设置中可手动固定语言，选择持久化。
2. **只翻译界面文案**：比赛名称（CQ WPX、CQ WW、ARRL DX、IARU HF、JIDX）、业余无线电缩写（QSO、RST、CQ、TU、AGN、NIL、QSB、DXCC、ITU、UTC、DX、W/VE）保持英文/原样；界面标签、说明、提示、错误信息全部翻译。
3. 不修改版本号、不写 release notes；发布流程另行处理。

非目标：RTL、平台原生菜单本地化（Windows/MSIX、macOS Info.plist）、英语以外的日志文案。

---

## 2. 现状分析

- 项目没有任何本地化基础设施：无 `l10n.yaml`、无 ARB、无 `flutter_localizations`。
- Flutter 版本固定为 `3.47.5`（`.fvmrc`），该版本的 gen-l10n **不支持** synthetic package，需把生成文件写入源码目录，并保留 `flutter: generate: true`。
- 现有用户可见字符串分散在以下位置：
  - `lib/ui/**`：设置面板、主界面、按键提示、复盘浮层、崩溃页、结果表、诊断面板。
  - `lib/contest_type/contest_definition.dart`：比赛名称、交换标签、计分说明。
  - `lib/contest_type/station_exchange.dart`：`validateStationExchange` 直接返回英文错误信息。
  - `lib/training/training_profile.dart`、`lib/audio/accent_policy.dart`：模式/难度/口音枚举自带英文 `label`。
  - `lib/error_handling.dart`：崩溃上报结果的 toast（无 `BuildContext`，由 Catcher2 回调）。
- `AppSettings` 当前在 `HomePage` 内创建；`SharedPreferencesWithCache` 在 `_MainAppCubit.load` 中加载。语言设置需要在 `MaterialApp` 之上生效，因此要调整 `MainApp` 的所有权。
- `TrainingRunMetadata.contestName`、`modeId`、`difficultyId` 会被写入历史记录并用于回放。**这些持久化值必须保持稳定**，本地化只在展示层做映射。
- 现有 UI 测试直接断言英文字符串，且测试里的 `MaterialApp` 没有注册 `AppLocalizations` delegates；新增语言菜单后，`find.text('Auto')` 会与口音菜单的 `Auto` 冲突，需要同步调整测试。
- `.gitignore` 已忽略 `/build/` 与 `.dart_tool/`，但生成目录 `lib/l10n/generated/` 需要新增忽略规则，避免提交生成代码。

## 3. 方案总览

采用 Flutter 官方 `gen_l10n`（ARB → `AppLocalizations`）：

1. 4 个 ARB 文件承载所有界面文案，模板为 `app_en.arb`。
2. `l10n.yaml` 指定 ARB 目录、生成目录、语言顺序。
3. `AppSettings` 新增 `AppLanguage`（`auto`/`en`/`zh_Hans`/`zh_Hant`/`ja`）与 `ValueNotifier<AppLanguage>`；`MainApp` 监听 notifier 切换 `MaterialApp.locale`。
4. 系统语言解析：`ja → ja`；`zh` 按 script/country 分流（`Hant` / `TW` / `HK` / `MO` → 繁体，其余 → 简体）；`en` → 英文；其他 → 英文。
5. 领域模型（比赛、模式、难度、口音、Exchange 字段）通过 `AppLocalizations` 扩展方法按稳定 id 映射，**不改动持久化 id**。
6. `validateStationExchange` 改为返回**结构化错误**，由 UI 层用当前语言格式化。
7. 对无 `BuildContext` 的崩溃 toast，新增 `AppL10n.current` 单例，由 `MaterialApp.builder` 在本地化变化时更新。

### 4.3 新增本地化辅助文件

**`lib/l10n/locale_resolution.dart`**

```dart
Locale? appLanguageLocale(AppLanguage language);
Locale resolveAppLocale(List<Locale>? preferred, Iterable<Locale> supported);
```

- `auto` 返回 `null`，交给 `localeListResolutionCallback`。
- 手动语言返回与生成 `supportedLocales` 完全匹配的 Locale（`zh` + `Hans`/`Hant`）。
- `resolveAppLocale` 按 §3 第 4 条规则遍历系统首选语言；无法识别时回退英文。
- 用 `supported` 列表匹配语言 + script，避免 `zh_TW` 被错误匹配成简体的默认 Flutter 行为。

**`lib/l10n/domain_l10n.dart`**

`AppLocalizations` 扩展方法，按稳定 id/枚举映射文案：

```dart
extension DomainL10n on AppLocalizations {
  String trainingModeLabel(TrainingMode mode);
  String trainingModeLabelById(String? id);       // 历史记录 / 复盘用
  String trainingDifficultyLabel(TrainingDifficulty difficulty);
  String trainingDifficultyLabelById(String? id);
  String phonicTypeLabel(PhonicType type);
  String incomingAccentLabel(IncomingAccent accent);
  String stationFieldLabel(String id, String fallback);   // 按 field.id 映射
  String? stationFieldHelper(String id);                   // 未知 id 返回 null
  String contestExchangeLabel(String contestId, String fallback);
}
```

- 比赛名继续使用 `ContestDefinition.name`；仅交换标签需要映射。
- 未知 id 回退到领域模型自带的英文 `label`/`helperText`。

**`lib/l10n/app_l10n.dart`**

```dart
class AppL10n {
  AppL10n._();
  static AppLocalizations? _current;
  static AppLocalizations get current =>
      _current ??= lookupAppLocalizations(const Locale('en'));
  static void update(AppLocalizations value) => _current = value;
}
```

- 供 `error_handling.dart` 等无 `BuildContext` 的代码使用。
- `MaterialApp.builder` 每次构建/语言切换时调用 `AppL10n.update(AppLocalizations.of(context))`。
- 首帧前发生崩溃时回退英文。

### 4.4 语言设置与 AppSettings

**`lib/settings/app_settings.dart`**

```dart
enum AppLanguage {
  auto('auto'),
  english('en'),
  simplifiedChinese('zh_Hans'),
  traditionalChinese('zh_Hant'),
  japanese('ja');

  const AppLanguage(this.id);
  final String id;

  static AppLanguage fromId(String? id) =>
      values.firstWhere((it) => it.id == id, orElse: () => auto);
}
```

- 构造函数增加可选外部 notifier，便于 `MainApp` 在 `MaterialApp` 之上监听：
  ```dart
  AppSettings({
    required SharedPreferencesWithCache prefs,
    ValueNotifier<AppLanguage>? languageNotifier,
  }) : _prefs = prefs,
       languageNotifier = languageNotifier ??
           ValueNotifier(AppLanguage.fromId(prefs.getString(_settingLanguage))) {
    this.languageNotifier.value =
        AppLanguage.fromId(prefs.getString(_settingLanguage));
  }
  ```
- 新增：
  ```dart
  AppLanguage get language => languageNotifier.value;
  set language(AppLanguage value) {
    _prefs.setString(_settingLanguage, value.id);
    languageNotifier.value = value;
  }
  ```
- 新增常量 `_settingLanguage = 'setting_language'`。
- notifier 由 `MainApp` 持有并释放；`AppSettings` 不负责 dispose。

### 4.7 领域层：校验错误结构化

**`lib/contest_type/station_exchange.dart`**

新增：

```dart
sealed class StationExchangeValidationError {
  const StationExchangeValidationError(this.field);
  final StationExchangeField field;
}

final class StationExchangeMissing extends StationExchangeValidationError { ... }
final class StationExchangeInvalid extends StationExchangeValidationError { ... }
final class StationExchangeOutOfRange extends StationExchangeValidationError {
  const StationExchangeOutOfRange(super.field, {required this.min, required this.max});
  final int min;
  final int max;
}
```

`validateStationExchange` 返回类型改为 `StationExchangeValidationError?`：

- 缺值 → `StationExchangeMissing(field)`
- 非数字 / validator 失败 → `StationExchangeInvalid(field)`
- 超范围 → `StationExchangeOutOfRange(field, min: field.min!, max: field.max!)`

UI 在 `_RunBtnCubit` 中格式化：

- `StationExchangeMissing` → `l10n.fieldRequired(label)`
- `StationExchangeInvalid` → `l10n.fieldInvalid(label)`
- `StationExchangeOutOfRange` → `l10n.fieldRange(label, min, max)`
- `label` 通过 `l10n.stationFieldLabel(field.id, field.label)` 获取。

更新相关测试断言为类型断言（见 §5）。

## 6. 假设与决策

1. 系统语言为 `zh` 但无 script/country 时按**简体**处理；`zh_TW`/`zh_HK`/`zh_MO`/`zh_Hant` 按繁体。
2. 不支持的系统语言一律回退英文。
3. 语言切换在比赛进行中禁用，与其他设置项一致。
4. 历史记录中的 `contestName`、`modeId`、`difficultyId` 保持原值；界面展示时才本地化，保证回放/历史兼容。
5. `AppLocalizations` 生成文件不提交，由 `flutter pub get` 生成；`.gitignore` 增加生成目录。
6. 不新增第三方 i18n 依赖，只用 SDK 自带 `flutter_localizations` + 已存在的 `intl`。
7. 本次不修改版本号、不新增 release notes、不改 CI。
