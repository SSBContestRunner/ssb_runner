三个方向

点击卡片打开可交互原型 · 右上角切换主题

A · Console

推荐

双栏布局：左侧日志与输入，右侧练习卡。信息最完整，最接近现有使用习惯； F 键收成单行，设置改为 4 页签侧边抽屉（比赛与电台合并），分数与计时合并成一张紧凑的会话卡。

侧边设置 · 单行按键 打开原型

B · Focus

任务优先

导航栏 + 居中任务区：主界面只保留当前收报、输入和最近 4 条；日志与统计变成独立视图。 设置使用全屏分类对话框，适合希望减少干扰、专注听抄的场景。

全屏设置 · 动作面板 打开原型

C · Ribbon

日志优先

78px 单行概览 + 全宽日志 + 底部操作台：计时、分数和统计压成一条 ribbon， 日志成为视觉主体，新增前缀列。适合看重通联复盘、需要一次看到更多记录的场景。

侧边设置 · 单行按键 打开原型

设计决策

针对四个原始问题
01

符合 Material Design 3

使用 color roles、type scale、state layer、focus ring 与 tonal elevation； 按钮层级收敛为 Filled / Tonal / Outlined / Text 四级。

02

Function keys 收纳

F1–F12 从 3×4 面板收成 38px 行内操作；B 只显示当前上下文 6 个， 其余进入底部动作面板，完整键位随时可查。

03

设置不再长滚动

A 将联动的比赛与电台合并为「比赛与电台」，与训练 / 音频 / 系统组成四类； B 使用全屏分类对话框，C 存档保留五类侧边抽屉，首屏即可完成常用配置。

04

分数与计时收紧

已验证总分成为主角，原始分与更正数降为辅助信息； 计时、进度、运行状态合并，为日志或输入区让出约 200px 高度。
